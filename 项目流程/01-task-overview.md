# 1. 任务描述

## 核心任务

使用 SO101 双臂机械臂，通过遥操作录制专家示教数据，用 SmolVLA 算法训练模型，最终让机械臂学会在随机位置抓取小方块并放入盘子中。录制三种颜色的小方块是为了提高模型泛化性，颜色本身不是任务核心。盘子位置也是随机的且盘子很小（8.5cm 直径），放置精度要求极高，这是本项目的主要难点。

> 硬件为幻尔（Huaner）SO101 机械臂 + 幻尔双摄像头（普通 RGB，无深度功能）。

## 物理环境

| 物品 | 尺寸 | 颜色 | 说明 |
|------|------|------|------|
| 小方块 | 3.5cm 边长 | 绿色、葡萄紫、橙色 | 体积小，对抓取精度要求高 |
| 盘子 | 8.5cm 直径 | 白色 | 直径仅方块边长的 2.4 倍，放置容错空间小 |

## 任务难点

1. **小盘子精度要求高**：8.5cm 直径的盘子配合 3.5cm 方块，留给机器人的容错空间很小。机械臂必须精确控制末端位置才能成功放入。
2. **非定点操作**：盘子和方块每次随机摆放在桌面上不同位置，机器人需要基于视觉信息动态定位目标，无法走固定轨迹。
3. **多颜色区分**：三种颜色的方块要求模型理解语言指令（如"put small green block in plate"）并定位正确颜色的目标。
4. **干扰物干扰**：桌面上可能混有 1-2 个不同颜色的方块作为干扰，模型需要忽略干扰物、只抓取指令中指定的颜色。
5. **光照变化**：实际环境光照会变化，模型需要一定程度的鲁棒性。

## 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                 移动固态硬盘 (Ubuntu 22.04)                │
│  ┌─────────────┐  ┌──────────────┐  ┌────────────────┐  │
│  │ LeRobot     │  │ PyTorch      │  │ NVIDIA Driver  │  │
│  │ v0.5.1      │  │ 2.10+cu128   │  │ 580-open       │  │
│  └─────────────┘  └──────────────┘  └────────────────┘  │
│                   ↕ USB ↕                                │
│  ┌─────────────┐  ┌──────────────┐  ┌────────────────┐  │
│  │ SO101 主臂  │  │ SO101 从臂   │  │ 双摄像头        │  │
│  │ (Leader)    │  │ (Follower)   │  │ front + top    │  │
│  └─────────────┘  └──────────────┘  └────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

- **主臂（Leader）**：人类操作员的输入设备，操作员拖拽主臂来控制从臂
- **从臂（Follower）**：实际执行任务的机械臂，跟随主臂运动或由模型自主控制
- **front 摄像头**：安装在机械臂末端，提供爪子视角
- **top 摄像头**：固定在顶部，提供第三视角俯视图

## 工作模式

本项目涉及三种工作模式：

| 模式 | 控制方式 | 用途 |
|------|----------|------|
| 遥操作 (Teleoperation) | 人类通过主臂遥控从臂 | 测试设备、确定参数 |
| 数据录制 (Recording) | 人类遥控 + 自动记录 | 采集训练数据 |
| 模型推理 (Inference) | SmolVLA 模型自主控制 | 验证训练效果 |
