# 8. 项目总结

## 技术栈

```
算法层    SmolVLA 策略（基于预训练 VLM 微调）
框架层    LeRobot v0.5.1 (HuggingFace)
基础层    PyTorch 2.10 │ CUDA 13.0 │ conda
硬件层    SO101 双臂 │ 双摄像头 │ NVIDIA RTX 5070
```

## 项目全流程

```
硬件准备          系统搭建           开发环境
  │                 │                  │
  ├─ BIOS 更新      ├─ Ubuntu 便携系统   ├─ conda + LeRobot
  ├─ NVIDIA 驱动    ├─ 基础工具         ├─ SO101 连接与校准
  └─ CUDA + PyTorch └─ 网络/镜像        └─ 双摄像头配置
                                           │
                                           ├─ 4处源码修改
                                           └─ 遥操作验证

 任务规划           数据采集           模型训练
  │                 │                  │
  ├─ 场景分级(L1-L3) ├─ 绿色 v1→v6     ├─ 预训练模型准备
  ├─ 三色指令        ├─ 葡萄紫 v1       ├─ 第1轮 10000→25000步
  ├─ 数据量 90+120   ├─ 橙色 v1         ├─ 第2轮 40000步(重训)
  └─ 光照策略        ├─ 第二批 120条     ├─ 第3轮 V3 40000步
                     ├─ 回放验证         └─ batch_size 8→36
                     └─ 合并数据集

 模型推理
  │
  ├─ V1/V2 (25000步/60s) → 三色全覆盖
  └─ V3 (40000步/120s)    → 更长推理时间
```

## 关键经验

1. **硬件适配先行**：RTX 5070 (新架构) + 老主板 → BIOS 更新 + open 版驱动。显卡驱动的坑不要留到后面。
2. **框架源码修改**：开源框架（LeRobot）不可能完美适配你的硬件/场景组合，做好阅读和修改源码的准备。本项目修改了 4 处。
3. **离线优先**：HuggingFace 在国内直连不稳定，训练和模型下载都要准备好离线方案（`HF_HUB_OFFLINE=1` + U 盘拷贝）。
4. **完全手动录制模式**：`reset_time_s=9999` + 键盘 →/ESC 控制录制节奏，比自动计时更灵活。
5. **录制迭代是常态**：第一条数据几乎必定有问题。录完立刻 `lerobot-replay` 回放确认。数据集 ID 带版本号追溯。
6. **多轮训练迭代**：先快速跑一轮验证流程，再加大步数和大 batch 做正式训练。Resume 不可靠时，重训比 debug 更省时间。
7. **随机放置 + 光照变化 = 真实泛化**：不依赖固定位置和固定光照的数据采集方式，让模型面对真实世界的不确定性。
