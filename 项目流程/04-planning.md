# 4. 任务规划与方案设计

## 算法选型

选择 **SmolVLA**（基于 lerobot/smolvla_base 预训练模型微调）而非 ACT，主要考虑：

- SmolVLA 基于预训练 VLM（视觉语言模型），在少量微调数据下泛化能力更强
- 原生支持语言指令引导（如 "put small green block in plate"），天然适配多颜色区分任务
- 对遥操作示教数据的利用效率更高

### 预训练模型

- 来源：HuggingFace `lerobot/smolvla_base`
- 大小：约 906MB（model.safetensors + config.json）
- 输入：双摄像头图像 + 语言指令
- 输出：机械臂 6 关节动作（5 自由度 + 夹爪）

## 数据集设计

### 场景复杂度分级

为覆盖不同难度的任务场景，设计了三个级别：

| 级别 | 描述 | 桌面物体 | 难度说明 |
|------|------|----------|----------|
| L1 - only | 仅目标方块 + 盘子 | 1个方块 | 基础任务，无干扰 |
| L2 - +1 distractor | 目标 + 1个不同色方块 + 盘子 | 2个方块 | 需区分指令中的颜色 |
| L3 - +2 distractors | 目标 + 2个不同色方块 + 盘子 | 3个方块 | 最高干扰级别 |

干扰物可以是不同颜色的小方块，也可以是圆形物体或大块积木。

### 任务指令（Language Instructions）

每轮任务通过英文指令指定要抓取的颜色，模型需根据指令定位正确目标：

| 颜色 | 指令 |
|------|------|
| 绿色 | `put small green block in plate` |
| 葡萄紫 | `put small grape block in plate` |
| 橙色 | `put small orange block in plate` |

### 数据量规划

| 批次 | 组成 | 条数 | 说明 |
|------|------|------|------|
| 第一批（baseline） | 3色 × 3场景 × 10条 | 90条 | 基础数据，每场景每种颜色各10条 |
| 第二批（增强） | 每色增加40条（20 only + 20 干扰） | 120条 | 含光照变化和更多位置随机 |
| 总计 | | 210条 | 每色约70条 |

## 数据采集策略

### 放置方式：随机而非定点

盘子和方块在每次 episode 中都**随机摆放在桌面不同位置**，而非固定标记点。这对模型提出了更高要求——不能依赖固定的运动轨迹，必须通过视觉实时定位。具体方式：
- 录制每条 episode 前，在复位阶段手动随机摆放盘子和方块
- 方块朝向也随机（不同面朝上）
- 盘子位置在桌面工作区域内任意放置

### 光照控制策略

为了平衡数据一致性（方便模型学习基础模式）和多样性（增强光照鲁棒性）：

| 条件 | 操作 | 目的 |
|------|------|------|
| 标准光照 | 窗帘完全拉上，固定灯光角度 | 保证基础数据的环境光一致 |
| 增强光照 | 部分拉开窗帘 | 引入自然光变化 |
| 增强光照 | 改变灯光角度 | 制造不同方向的阴影和反光 |

基础数据和增强数据按比例混合，最终构成完整的 210 条训练集。
